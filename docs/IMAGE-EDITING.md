# 画像編集の強化 — 1.7.0

更新: 2026-09-13

## 実装済み: 選択範囲のモザイク

画像ビューアの「編集」→「選択」で矩形・楕円・投げ縄を使って範囲を選ぶ。
「追加」「除外」で範囲を修正し、「モザイク」で粒度の調整画面に入る。
プレビューを確認して「適用」で確定する。「キャンセル」または戻る操作で調整を破棄できる。
適用後は既存の Undo / Redo で取り消し・やり直しができる。

- 粒度は画像の短辺に対する 0.5〜8%（最小 2px）。既定は 2.5%。
- 調整中の操作は履歴に積まず、適用時に一手だけ記録する。
- 元画像と `Layer.Mosaic` の指示を保持し、プレビューと保存で同じレンダラーを使う。
- モザイク範囲は切り抜き・90度回転・反転に追従する。
- 各ブロックの全画素を平均し、透明画素の隠れた RGB は平均に混ぜない。
- 半透明画像でも元の細部が重ならないよう、対象の画素を置換する。
- ブロック単位で処理し、出力画像全体の追加コピーを作らない。
- スライダー操作は 100ms のデバウンスと描画キャンセルを行う。
- 描画中の元画像キャッシュが別の処理に解放されないよう貸し出しを同期する。
- 調整中の保存、プレビュー失敗時の適用、保存中の編集を抑制する。

## 人物・物のタップ自動選択: 導入案、未実装

既存の非公開設計書 `IMAGE-EDITOR-DESIGN.md` §11 は「新規の依存ライブラリ：追加しない」
と定めている。その制約変更をユーザーに確認中。ライブラリやモデルはまだ追加していない。

候補は Google の MediaPipe InteractiveSegmenter と MagicTouch。
MagicTouch は画像中の点を指定して人物・動物・物の領域を推定する約 6MB のモデルで、
モデルカードには Apache License 2.0 が示されている。
出典: [Google の MagicTouch モデルカード](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20MagicTouch.pdf)。

具体的な組み込み案:

1. `app` モジュールに `com.google.mediapipe:tasks-vision:0.10.35` とモデルを固定して同梱する。
   この版の [公式 API 実装](https://github.com/google-ai-edge/mediapipe/blob/v0.10.35/mediapipe/tasks/java/com/google/mediapipe/tasks/vision/interactivesegmenter/InteractiveSegmenter.java)
   は点指定の `RegionOfInterest` とマスク出力を提供する。
   1.0.0 系の新しい API とは分けて互換性を確認する。
2. 「選択」に「人物・物」を追加し、1 本指のタップを論理キャンバス上の点へ変換する。
   2 本指はズーム・移動のままにする。
3. 切り抜き・回転を反映した画像の専用コピーを、バックグラウンドで端末内推論へ渡す。
   画像のアップロードや実行時のモデル取得は行わない。
4. 推論結果を穴・離れた部分を扱える選択形状に変換し、既存のモザイク・塗り・透明化へ渡す。
   保存時は確定した選択を使う。推論の再実行で範囲を変えない。
5. 「追加」「除外」と手動の投げ縄で修正できるようにし、推論失敗時は現在の選択を保持する。
   処理中表示とキャンセルを設け、古いタップの結果が後の操作を上書きしないようにする。
6. モデルの配布元・ハッシュ・ライセンスを記録し、設定内のライセンス表示に追加する。

導入後に確認すること:

- タップとマスクの座標一致（余白、ズーム、回転、縦横比の異なる画像）。
- 人物の髪、細い物、背景と似た色の物、複数の人物について選択品質を目視評価する。
- 連打・キャンセル・Undo・画面終了時に古い結果やネイティブリソースを残さない。
- モデル同梱状態でのオフライン起動、ABI 対応、16KB ページサイズ、APK 増加量を確認する。
- 自動選択は誤認識しうるため、モザイク適用前に結果を確認・修正できる操作を維持する。

この案は承認と実装・実機評価を経てから出荷対象にする。
