# 動画編集の下書き — 1.12.0

更新: 2026-09-15 / versionName `1.12.0` / versionCode `102`

**動画編集の内容を自動で下書きに保存し、あとで続きから編集できるようにした。ビルド・実機ともに未確認。**
設計: [実装設計](VIDEO-EDITOR-ROADMAP.md) §11 / 書き出し: [書き出しの記録](VIDEO-EDITING-EXPORT-1.11.0.md)

## 使い方

| 場面 | 動き |
|---|---|
| 編集画面を開く | 新しい下書きを作る。トップバーに「保存中… / 保存済み / 下書きを保存できません」を出す |
| 編集する | 確定した操作（指を離した・適用した）の約 1 秒後に保存する。書き出し設定の変更も保存する |
| ほかのアプリへ切り替える | 待たずにその場で保存する |
| 戻る | 何も編集していない新しい下書きは残さずに閉じる。編集していれば「下書きを残して閉じる / 編集に戻る / 下書きを削除して閉じる」を出す |
| 画面の再生成・プロセスの終了 | 同じ下書きを開き直す（2 つ目を作らない） |
| ホームのメニュー →「動画編集の下書き」 | 一覧（名前・クリップ数と長さ・更新日時・容量）。タップで開き、ごみ箱で削除する |

## 保存の規則（画像編集の下書きと同じ）

- 保存先: `filesDir/video-drafts/<下書きの ID>/manifest-<revision 20 桁>.bin`
- 形式: 版番号付きの明示的なバイナリ（識別子 `FDXV`、版 1）。末尾に SHA-256
- 書き込み: 一時ファイル → sync → 読み戻して全項目が一致するか確認 → 改名で公開
- 正常な世代を新しい 2 つだけ残す。最新が壊れていたら 1 つ前を開き、そのことを知らせる
- 新しい版の Foldex で書かれた下書きは開かず、古い世代で置き換えない
- 同じ下書きを 2 つの画面で同時に開かない。使用中の下書きは一覧から消せない
- 元に戻す履歴と、指を離す前の途中の値は保存しない

## 素材の扱い

素材のファイルはコピーせず、元の場所（端末内のパス / content:// の URI）を参照する（設計書 §10）。
下書きを開いたときに見つからない素材があれば、その数を知らせる。
再リンク（別の場所のファイルを指定し直す）は未実装。見つからない素材がある状態で書き出すと、開始前に理由を出して止まる。

## 実機で確かめること

1. 編集 → ほかのアプリへ切り替え → アプリを強制終了 → ホームのメニューから下書きを開き、最後の操作まで戻るか
2. 何も編集せずに閉じたとき、一覧に下書きが増えないか
3. 閉じる確認の 3 つのボタンと、下書きを削除して閉じた後の一覧
4. 編集中の下書きが一覧で「別の画面で編集中」になり、開けない・消せないこと
5. 素材を移動してから下書きを開いたときの案内と、書き出しを始めたときの止まり方
6. 画面の回転・200% の文字で、トップバーの保存状態の表示が崩れないか
