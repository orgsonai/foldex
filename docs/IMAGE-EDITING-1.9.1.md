# Foldex 画像編集 1.9.1 — 終了画面のボタン配置

対象: 1.9.1 / versionCode 97。

## 修正

「編集を終了」で「下書きを残して閉じる」を AlertDialog の確定枠、残りの三つをキャンセル枠の Column へ配置していたため、枠同士の幅計算で長いラベルが折り返され、配置が不揃いになっていた。

専用の終了ダイアログへ切り出し、同じ幅で次の順に縦へ並べる。

1. 下書きを残して閉じる
2. 保存する
3. 下書きを破棄して閉じる
4. 編集に戻る

主操作を塗りつぶしボタン、画像保存を枠付きボタン、破棄をエラー色のテキストボタンで示す。文字は中央揃えで折り返し、各ボタンの高さは最低 48dp を確保する。
説明と操作全体をスクロールできるようにし、狭い画面・横画面・文字拡大でも下の操作へ到達できる構造にした。
保存・破棄・戻る操作の接続先と、ダイアログ外タップ/戻るキーで編集へ戻る動作は維持する。
