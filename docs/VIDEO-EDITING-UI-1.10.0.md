# 動画編集の画面試作 — 1.10.0

更新: 2026-09-14 / versionName `1.10.0` / versionCode `98`

**動画編集の画面だけを試作した。音声の再生・保存・書き出しは動かない。**
目的は、タイムラインの操作感と画面の構成を実機で確かめること。
設計: [実装設計](VIDEO-EDITOR-ROADMAP.md) / [商用製品との比較](VIDEO-EDITOR-COMPARISON.md)。
実装設計 §15 の確認事項への回答前のため、compileSdk・Media3 の更新と部品の追加はしていない。新規依存なし、MIT 維持。

## 入口

- 動画のビューア右上の「はさみ」(動画を編集)。端末内のファイルのときだけ表示する。
- ファイル一覧の複数選択 → メニュー「動画編集で開く」。選んだ順に並ぶ。NAS・SAF のファイルは除き、除いたことを知らせる。

## 試作でできること

| 領域 | 内容 |
|---|---|
| タイムライン | 再生位置は画面中央に固定。1 本指でスクロール (指を離すと慣性で進む)、2 本指で拡大縮小、目盛りのタップでその位置へ移動 |
| クリップ | タップで選択と解除。選んだクリップの端をドラッグしてトリム (再生位置などに吸着し、触覚で知らせる)。メインは長押しで並べ替え、文字・音声は長押しで位置を移動 |
| 編集 | 分割・削除・複製、速度 (0.1〜16 倍)、音量とフェード、90° 回転と左右反転、はめ込む／埋める、文字 (内容・大きさ・色・縁取り・表示時間)、キャンバスの比率と背景色 |
| 追加 | 動画・画像・音声をファイル選択から追加。文字は再生位置に置く |
| 表示 | 再生位置のコマを静止画で表示。スクロール・再生中は 0.25 秒単位で近いキーフレーム、止まると正確なコマを読み込む。文字はプレビュー上でドラッグして動かせる |
| 履歴 | 元に戻す・やり直す (100 手)。スライダー・ドラッグ・文字入力は操作の終わりに 1 手 |
| 書き出し画面 | 標準・高画質・容量指定・音声のみ・無劣化カットの選択、ビットレートと容量の見積もり、画質の下限を下回るときの解像度の提案。書き出しの処理は未実装 |
| 読み上げ | タイムラインに説明と「前/次のクリップを選択」「分割」の操作を付けた。1 コマ送りのボタンがある |

画面の構成: 縦画面は上から トップバー → プレビュー → 時刻と再生の行 → タイムライン → 設定パネル → 操作列。
横画面はプレビューの右に設定パネルと操作列、タイムラインは下に全幅。

## 試作として割り切ったこと

- 音は出ない。「再生」は再生位置を実時間で進め、静止画のコマを切り替えるだけ。
- 音声クリップの波形は仮の形 (素材の時刻から決まる疑似的な値)。実際の音は解析していない。
- プロジェクトは保存しない。編集後に閉じるときは確認を出す。
- 時刻は 30fps の格子で扱う。素材の実際のフレーム時刻の索引 (実装設計 §6-4) は未実装。
- 切り抜きの範囲指定、キーフレーム、切り替え効果、重ねる映像の段は未実装。
- 素材の長さ・寸法は MediaMetadataRetriever の値をそのまま使う。

## 実機で確かめること

1. ビューアの「はさみ」と、ファイル一覧の複数選択から開けるか。NAS のファイルを混ぜたときの案内。
2. スクロール・慣性・ピンチの追従、目盛りのタップ、中央の再生位置の見やすさ。
3. トリムの取っ手のつかみやすさ、吸着と触覚、左端のトリムで端が指の下に残るか。
4. 長押しの並べ替え・移動、画面端での送り。
5. 分割・削除・複製・速度・音量・変形・文字・比率のパネル、元に戻す・やり直す。
6. プレビューのコマの切り替わり (スクロール中と停止後)、文字のドラッグ。
7. 横画面、200% の文字、TalkBack、英語表示。
8. 書き出し画面の見積もりと解像度の提案。
