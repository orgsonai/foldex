# Foldex 画像編集 1.9.0 — 選択ブラシとモザイクの再調整

対象: 1.9.0 / versionCode 96。CE1 の最初の実装単位。
目標は商用アプリと同等の機能・品質。商用出荷は行わない。
Foldex 本体は MIT を維持し、新規依存・モデル・通信処理の追加はない。

## 操作

### 選択をブラシで修正する

1. 「選択」→「人物・物」で対象をタップする。矩形・楕円・投げ縄からも始められる。
2. 「ブラシ」を選び、「追加」または「除外」で範囲をなぞる。「新規」は一筆の範囲へ置き換える。
3. 太さはスライダーと ± ボタンで変更する。タップだけでも円形の範囲を作れる。
4. 指の反対側に表示する拡大窓、緑の追加範囲・赤の除外範囲を見ながら修正する。
5. 確定した選択にモザイク・塗りつぶし・透明化を適用する。

一筆を Undo 一手として扱う。矩形・自動選択・反転・解除も取り消しとやり直しの対象。
2 本指へ切り替えた場合は描きかけを取り消し、拡大・移動する。画面寸法の変化やジェスチャー中断でも半端な一筆を確定しない。
長すぎる一筆（4,096 点超）は途中まで適用せず、短く分ける案内を出す。

確認背景は市松・白・黒を切り替えられる。透明部分の確認用で、出力画像の背景設定は変わらない。
拡大窓は現在のプレビューを 2 倍で表示する。原画像の高解像度部分を追加デコードする機能ではない。
選択とモザイクのパネルは縦スクロールでき、使える高さの半分以内に収めてキャンバスを残す。

### 適用済みのモザイクを直す

1. 「選択」→「適用済みモザイクを調整」で番号と粒度から対象を選ぶ。
2. 粒の大きさを調整する。切り抜き後も、現在の粒度をスライダーの範囲に含める。
3. 「範囲を修正」でブラシ・図形・反転・解除を使う。この間、対象のモザイクだけを一時的に隠す。
4. 「効果を確認」で修正後の絵を確認してから「適用」する。

調整中も一筆・一度の粒度操作ごとに Undo/Redo が使える。「キャンセル」は調整前へ戻す。
「適用」は文書の履歴一手になる。「削除」は確認後、選んだモザイクだけを除き、Undo で戻せる。
新規モザイクでも適用前に同じ範囲修正を使える。未確定の調整は自動保存の対象に含めない。

既存のモザイクは同じ ID・描画順のまま置き換える。後ろへ複製して重ねず、上の文字・塗りつぶしや別のモザイクとの順序を維持する。
これは従来の `Layer.Mosaic` の再編集であり、合成の最後に必ず描く新しい目隠しの仕様とは別。

## データと互換性

- 最初のブラシは硬い境界を持つ。点列・半径・キャンバスのクリップを `SelectionSpec.BrushStroke` に論理 px で記録する。
- 既存選択へ追加・除外を合成し、穴と離れた領域を保持する。モデルの点判定と、プレビュー・出力の Android Path で同じ幾何形状を扱う。
- 表示ズームの値を保存せず、90° 回転・反転・切り抜き時に点列とクリップを変換する。出力寸法を変えてもプレビューの画素へ固定されない。
- ビットマップを Undo ごとに複製しない。今回の硬いブラシにはラスターマスク資産を必須にせず、半透明マスク・境界ぼかしの導入を CE1 の後続へ分けた。
- 下書き schema は 2。schema 1 の 1.8.5 下書きを読み込める。保存時には新形式を使い、直前の正常な旧世代も残す。
- 1.8.5 は schema 2 を非対応として拒否する。新しいブラシを読み飛ばして異なる範囲の画像を保存することはしない。
- 文書、選択、適用済みモザイクは復元する。調整中のモザイク、過去の Undo、ブラシの設定、表示背景・ズームは復元対象外。

## 検証

- 画像編集の JVM テスト **221 件成功**（1.8.5 の 195 件から 26 件追加）。失敗・エラー・スキップ 0。
- 追加検証: タップ・高速移動・繰り返し点・曲がり・穴・ズーム座標・端のクリップ・回転/反転/切り抜き・Undo、モザイクの置換順序・一時非表示・適用/取消/削除・履歴・切り抜き後の粒度。
- 下書きは **1.8.5 の実際の Writer で生成した schema 1 の固定 fixture** を読み、新形式への保存と旧世代保持を確認。ブラシとモザイクの往復、旧 schema への未知型混入の拒否も確認。
- `:app:assembleDebug` と `:app:assembleDebugAndroidTest` 成功。
- Android 描画テストは計 **10 件の APK を作成**。今回、ブラシの形と論理判定の倍率別照合、モザイク再調整時の描画順を追加し、下書き復元後の実描画テストにもブラシを含めた。**実機での実行は未実施**。
- 日英の文字列 XML と重複、差分の空白エラーを確認。

実機ではブラシの追従、拡大窓、2 本指への切替、縦横画面、TalkBack/200% 文字、保存画素、プロセス終了後の復元を確認する必要がある。
現在のテスト結果だけで商用アプリと同等の選択精度や速度を達成したとは扱わない。
