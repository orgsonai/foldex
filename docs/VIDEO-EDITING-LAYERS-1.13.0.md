# 動画・画像の映像レイヤー — 1.13.0

更新: 2026-09-16 / versionName `1.13.0` / versionCode `104`

## できること

- メイン映像の上に動画・画像を追加する。追加先はその時点の再生位置。
- プレビューのドラッグで配置し、「レイヤー配置」で幅・不透明度・横位置・縦位置・90度回転・左右反転を調整する。
- 「手前へ」「奥へ」で重なり順を変える。文字は映像レイヤーより手前。
- 各レイヤーに独立したタイムラインの段を表示する。段の中央をドラッグして時間移動、両端でトリムする。メイン映像の前詰めとは独立している。
- 他の映像・文字・音声の端、再生位置、先頭へ吸着する。段が増えたときは縦スクロールできる。
- 分割、複製、削除、使用区間の移動、速度、音量、フェード、Undo/Redo。
- 配置・時間・重なり順を下書きに保存し、Media3の書き出し計画へ渡す。

新しい動画レイヤーの音声は初期状態でミュート。「音量」で解除できる。
「表示・音声を有効にする」を切ると、そのレイヤーの映像・音声を両方除外する。不透明度は映像だけに効く。

## 確認手順

1. メイン動画を追加し、クリップの選択を解除。下の操作列を横に送り「動画レイヤー」または「画像レイヤー」から追加する。
2. プレビューをドラッグして配置し、幅・不透明度・重なり順を変える。複数の素材が同時に見えることを確認する。
3. タイムラインのレイヤー中央を横へ動かす。メイン動画が並べ替わらず、レイヤーの表示時間だけが変わることを確認する。
4. 左端を縮めると右端が固定され、別のクリップへ近づけるとガイド線に吸着することを確認する。縦方向のドラッグで下の段へ移動できることも見る。
5. 途中で映像が変わる動画レイヤーを分割する。前半と後半の原本の時刻表示、プレビュー、書き出した動画が別の区間になっていることを確認する。
6. Undo/Redo、下書きを残して閉じる→再度開く、書き出しまで確認する。

## 実装上の判断

`LayerClip`は素材区間・速度・音量を既存の`MainClip`と共有し、絶対開始時刻と配置を別に持つ。
初版は1クリップにつき1段。分割後は前半と後半に別の段を作る。
下書き形式はschema 2へ更新し、schema 1を引き続き読めるようにした。Roomはv6のまま。

Media3 1.11.1は先に登録した映像が手前になるため、レイヤーを逆順に並べる。
最前面には1pxの透明PNGを指定fps・全長で置き、短いレイヤーや低fpsの素材で出力全体の長さ・fpsを決めないようにする。
各レイヤーの前後は空白で埋め、表示区間外の不透明度を0にする。出力寸法はキャンバスを明示する。
レイヤー映像を回転後の縦横比に合う寸法へ整えてから、正規化した中心位置で合成する。

公式APIと、導入版1.11.1の`DefaultVideoCompositor`・`SequenceAssetLoader`のソースを確認した。
[カスタム合成レイアウト](https://developer.android.com/media/media3/transformer/videocompositorsettings?hl=en)、
[VideoCompositorSettings](https://developer.android.com/reference/androidx/media3/common/VideoCompositorSettings)。
実機での精度・速度の確認は、上記のinstrumented testを実行してから判断する。

## 残る範囲

- プレビューは既存の静止フレーム方式で、音は再生しない。
- 動画の書き出しはメイン映像の長さまで。後ろのレイヤー・音声・文字を切る場合は書き出し前に案内する。メイン映像が必要。
- 同時デコードできる映像数・高解像度での実用速度は未計測。プロキシ、段のロック、任意角度の回転、キーフレームは未実装。
- 1.13.0の下書きを古いアプリで開くことはできない。旧版は新しい形式を上書きせず「未対応」と扱う。
